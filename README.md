# 🤖 AI Data Analyst Agent using LangChain

An AI-powered Data Analyst Agent that converts natural language queries into SQL, executes them on a database, and returns meaningful insights using Large Language Models.

This project demonstrates real-world use of **LangChain Agents**, **SQL Databases**, and **LLMs**, making it suitable for engineering projects, internships, and placements.

---

## 🚀 Features

- 🔍 Natural language to SQL conversion
- 🧠 AI Agent powered by LangChain
- 🗄️ Connects to SQL databases (SQLite / MySQL)
- 📊 Business insight generation
- 🧾 Interactive UI using Streamlit
- ☁️ AWS deployable architecture

---

## 🛠 Tech Stack

- Python
- LangChain
- OpenAI / HuggingFace LLM
- SQL (SQLite / MySQL)
- Streamlit
- Pandas
- AWS (EC2 / ECS)
